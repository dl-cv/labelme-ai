# 新功能怎么套复制粘贴那套门禁

模板就是 copy/paste，不要发明第二种哲学。

## 必须先切开的边界

- 纯逻辑：`labelme/dlcv/utils/<feature>.py` 或现有 mixin（例如 clip_paste）
- Qt 接线：快捷键、信号、widget。薄。
- 禁止改上游 `labelme/app.py`；产品 action 在 `labelme/dlcv/app.py` 的 `_init_ui` 里改/藏/初始化。
- 禁止把算法写进上游 `labelme/app.py`

## 四层门（按顺序）

1. **Gherkin**：用户能看见的 Given/When/Then，放 `tests/features/<feature>.feature`，场景先 2～3 条。
2. **单测**：边界（空输入、超边、连点累加、异路径）。GUI 用 `agg`，能假依赖就假依赖。
3. **覆盖率**：对纯函数模块设 `--cov-fail-under`（copy-paste 是 90%）。在 `Makefile` 加 `test-<feature>` / `coverage-<feature>`。
4. **变异测试**：只打纯函数文件。Windows 用 **cosmic-ray**，不用 mutmut。阈值参考 copy-paste 的 kill ≥ 80%。

最后可做一个 `tools/qa_<feature>.py` 汇总，仿 `tools/qa_copy_paste.py`。

## Agent 会话怎么切

- 规格：只改 feature + 失败的测试骨架
- 编码：改实现直到 `make test-<feature>` 绿
- 清理：`make lint`，别把逻辑塞回 app.py
- 强化：coverage + cosmic-ray；有活变异体就补测，不要先放宽阈值

## Qt 例外

下列没有 gauntlet 就不算「可以不看代码」：

- QGraphics 画布观感、十字准星、亮度对比度滑条手感
- 快捷键与系统/控件抢焦点
- 闪退、线程/信号生命周期

这些：最小复现测如果写得出就写；写不出就人点一次，diff 重点看接线而不是算法。
