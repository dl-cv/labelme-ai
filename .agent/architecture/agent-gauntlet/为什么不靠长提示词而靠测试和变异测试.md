# 为什么不靠长提示词而靠测试和变异测试

长 `AGENTS.md` / `claude.md` 对模型像《加勒比海盗》法典：听起来是规则，执行时是建议。上下文一长，中间规则 Lost in the Middle。

确定性工具不会把第 80 条规则当成建议：pytest 红就是红，覆盖率不到 90 就是失败，cosmic-ray 活变异体就是测试没咬住。

本仓库已经用这套罩住复制粘贴（Ctrl+C/V 多边形 vs 图片、同图偏移、超边裁切）。新模块照抄门，不要把规则再写进 Prompt。

Agent 也会被烂代码拖死：不清理会改 A 坏 B 绕圈。所以实现之后要有清理步（ruff、复杂度别堆在 `app.py`），不是一直往下堆功能。

规格驱动一次写完再实现，在本项目里禁止。改动成本低：做一点、跑门禁、看架构、人只在 Qt 壳层介入。
