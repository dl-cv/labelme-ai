# Copy / Paste Polygon — QA Checklist

手动验收（labelme DLCV）。每项打 `[x]`。

## Ctrl+C

- [ ] 选中 1 个多边形，Ctrl+C → toast「多边形已复制」
- [ ] 多选多边形，Ctrl+C → toast「多边形已复制」，Ctrl+V 粘贴全部
- [ ] 取消选中后 Ctrl+C → toast「图像已复制」，资源管理器可粘贴文件
- [ ] 复制图片后再 Ctrl+V：不应再粘出旧多边形
- [ ] 无打开图片且无选中 → 提示先选中图片
- [ ] Ctrl+D 仍复制选中多边形（兼容）

## Ctrl+V 位置

- [ ] 同一张图粘贴：相对原位置向右下偏移，不重合
- [ ] 切到另一张图粘贴：坐标与复制时一致
- [ ] 连续多次同图粘贴：每次再偏 5px

## 裁切

- [ ] 多边形跨出右/下边界：只保留图内部分，形状仍闭合
- [ ] 多边形完全在图外：不生成标注，有提示
- [ ] rectangle / line / point 超边行为符合预期
- [ ] 粘贴到更小图：超边被裁，不缩放变形（与旧「缩放适配」不同）

## 跟随鼠标

- [ ] 设置面板「其他设置」有「复制多边形跟随鼠标」，默认关
- [ ] 关闭：粘贴不跟鼠标
- [ ] 开启：粘贴后整体左上角在鼠标处
- [ ] 开启且贴到边缘外：裁切，不整体平移回图内
- [ ] Ctrl+Shift+V：即使开启跟随，也不跟鼠标（同图偏移 / 异图原坐标）
- [ ] 重启软件后开关状态保持

## 回归

- [ ] 撤销（Ctrl+Z）可去掉刚粘贴的形状
- [ ] 粘贴后形状被选中，可立刻拖动
- [ ] 标签名 / group_id / rotation direction 保持
- [ ] 英文 UI 下 toast 为 Image copied / Polygon copied
